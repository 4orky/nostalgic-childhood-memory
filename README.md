One sentence, one remembered evening: a grandmother, a rice pot, and a bowl set out for someone who never came.

Every evening at six my grandmother set an extra bowl beside the rice pot, just in case someone came by, and nobody ever did, but she set it anyway.

## How the winner was chosen

main.py holds twelve hand-written drafts, each graded on five yardsticks, and the strongest wins; a tie goes to the shorter draft, so every run writes the same bytes. The yardsticks, in order, are how much the line aches, how solid its textures feel, how true the small detail rings, how little fat it carries, and how long its echo lasts after the last word.

- **Ache:** the extra bowl is a small daily act of hope and love, the kind you only understand years later, when the kitchen is empty and there is nobody left to set a bowl for.
- **Texture:** six o'clock, the rice pot, the extra bowl — a time, a place and a smell, not an abstraction, and the hour itself does half the remembering.
- **Truth:** the honest detail is that nobody ever came. A greeting card would have had the visitor arrive; real life is a bowl set out anyway, night after night.
- **Economy:** 148 characters in one sentence, and the turn lands on the last five words, "but she set it anyway."
- **Echo:** the sentence ends on a habit that outlived its hope, and the warmth of it stays with you.

The runner-up was the bread-crusts line about the sparrows, at 44 points; the winner scored 47. A second pass added two polish checks — no doubled spaces, and a closing full stop — so no sloppy draft can win on points alone.

## Trying it out

Run it with python3 ./main.py and it writes the winning sentence to /output/entry.txt, then reads the file back and checks the bytes on disk match the chosen sentence exactly.
